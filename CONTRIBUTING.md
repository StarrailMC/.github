# Contributing to Voxaris Forge

Thanks for your interest in helping out! This guide applies to all Voxaris Forge repositories unless a specific project says otherwise.

## Getting Started

1. Join the [Discord](https://discord.gg/CFUYP246zU) — this is where the team coordinates, and it's the fastest way to ask questions before starting work.
2. Check the project's issue tracker for open tasks, or open a new issue to propose one before diving in on something big.
3. Fork the repo and create a branch for your change.

## Making Changes

- Keep pull requests focused — one feature or fix per PR is easier to review.
- Follow the existing code style in the project you're contributing to.
- Test your changes before opening a PR.
- Write a clear PR description explaining what changed and why.

## Submitting a Pull Request

- Fill out the PR template.
- Link any related issues.
- Be responsive to review feedback — we'll do our best to review promptly.

## Reporting Bugs / Suggesting Features

Open an issue using the appropriate template. Include as much detail as you can (steps to reproduce, expected vs. actual behavior, versions, etc.).

## Questions

If anything here is unclear, ask in the [Discord](https://discord.gg/CFUYP246zU).
